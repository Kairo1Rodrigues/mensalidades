Como conectar

  1. Toque em Gerar QR Code.
  2. No celular da escola, abra o WhatsApp e vá em Configurações › Aparelhos conectados › Conectar um aparelho.
  3. Aponte a câmera para o QR Code desta tela.
  4. Pronto: os comprovantes que chegarem passam a aparecer aqui sozinhos. O WhatsApp do celular continua funcionando normal.

Para não correr risco de bloqueio, o sistema só responde a quem mandou mensagem. Cobranças são enviadas uma a uma, por você.
